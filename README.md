# 🚀 VELORA AI

### ✨ Design With Flow

VELORA AI is a **Generative AI-powered UI/UX design platform** that creates modern, production-ready interfaces from simple text prompts. It combines intelligent design reasoning with real-time code generation to help developers and designers build faster.

---

## 🌟 Features

* 🎨 **AI UI Generation** – Generate complete UI layouts from prompts
* ⚡ **Real-time Preview** – Instantly visualize generated designs
* 🧠 **Design Reasoning** – Understand layout, color, and typography decisions
* 🌙 **Dark/Light Mode** – Seamless theme switching
* 💬 **AI Chat Assistant** – UI/UX guidance and prompt suggestions
* 📦 **Export Options** – Download HTML, ZIP, or convert to React/Tailwind
* 📊 **Modern UI Styles** – Glassmorphism, minimal, futuristic, and more

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Animations:** GSAP
* **Icons:** Font Awesome
* **AI Integration:** Google Gemini API
* **Other:** Responsive Design, CSS Variables

---


## 🧠 How It Works

1. User enters a UI idea (prompt)
2. Gemini AI analyzes the request
3. AI generates:

   * UI layout structure
   * Design reasoning
   * HTML/CSS code
4. Code is rendered in a live preview
5. User can copy or export the result
